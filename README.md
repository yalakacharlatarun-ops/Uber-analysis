# Power BI Dashboard Project 📊

## Overview
This project is an interactive Power BI dashboard designed to transform raw data into meaningful business insights.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## Key Features
- Interactive dashboards
- KPI cards
- Charts and graphs
- Data filtering using slicers
- DAX calculations
- Business insights and analysis
- User-friendly dashboard design

## Project File
The `.pbix` file contains the complete Power BI report, including data transformation, data modeling, calculations, and visualizations.

## Objective
The main objective of this project is to analyze data effectively and present important insights through interactive visualizations to support better decision-making.
